# 簡易版ダッシュボードレイアウト案

## 背景

現在の簡易版は全セクションが**縦一列**（max-w-5xl = 1024px）に並んでおり、PC画面でもスクロールが必要。
主要情報をスクロールなしで一覧できるダッシュボードレイアウトに変更したい。

**対象**: 簡易版のみ。詳細版は情報量が多いため現状の縦一列レイアウトを維持する。

---

## 現状の構造

```
┌──────────────────────────────┐
│  ヘッダー（銘柄選択・分析ボタン） │  max-w-5xl (1024px)
├──────────────────────────────┤
│  経済指標カレンダー             │  ~50px (折畳時)
│  ニュース                     │  ~30px (折畳時)
│  結論                        │  ~150px
│  PR比較 (Long | Short)        │  ~320px
│  売買シミュレーター             │  ~450px ← 最大
│  ポジション管理                │  ~200px+
│  分析履歴                     │  折畳可
└──────────────────────────────┘
  合計: 約1200px+ → スクロール必須
```

---

## 提案レイアウト

### PC (≥1440px) — フルダッシュボード

max-widthを7xl (1280px) または画面幅に拡張し、CSS Gridで配置。

```
┌─────────────────────────────────────────────────────────────┐
│  ヘッダー（銘柄選択・分析ボタン）  │  経済指標 🔴  │  ニュース 📰  │
├─────────────────────────┬───────────────────────────────────┤
│                         │                                   │
│  結論                    │                                   │
│  ┌─────────────────┐    │  売買シミュレーター                  │
│  │ ロングエントリー推奨 │    │  ┌───────────────────────────┐    │
│  │ 理由テキスト...    │    │  │ 投資金額  レバレッジ          │    │
│  └─────────────────┘    │  │ エントリー  損切り  利確       │    │
│                         │  │ ポジションサイズ               │    │
├─────────────────────────┤  │ 損益シミュレーション            │    │
│                         │  │ 清算価格 / 保有時間            │    │
│  PR比較                  │  │ [指値注文として登録]            │    │
│  ┌──────────┐           │  └───────────────────────────┘    │
│  │ ロング    │           │                                   │
│  │ Entry/SL/TP│          │                                   │
│  │ PR: 1.59  │           │                                   │
│  ├──────────┤           │                                   │
│  │ ショート   │           │                                   │
│  │ Entry/SL/TP│          │                                   │
│  │ PR: 3.31  │           │                                   │
│  └──────────┘           │                                   │
├─────────────────────────┼───────────────────────────────────┤
│  ポジション管理           │  分析履歴                          │
│  (max-height: 250px)    │  (max-height: 250px)              │
│  [内部スクロール]         │  [内部スクロール]                   │
└─────────────────────────┴───────────────────────────────────┘
```

**Grid定義:**
```css
grid-template-columns: 2fr 3fr;
grid-template-rows: auto 1fr auto;
grid-template-areas:
  "header  header"
  "left    simulator"
  "pm      history";
```

**設計意図:**
- **左列 (40%)**: 結論 + PR比較 = 「何をすべきか」の判断情報
- **右列 (60%)**: シミュレーター = 「どう実行するか」の操作エリア
- **下段**: ポジション管理 + 分析履歴 = 記録・管理エリア（高さ固定、内部スクロール）
- **ヘッダーバー**: 経済指標・ニュースはアイコン+折畳式でヘッダーに統合

## コンポーネント別の対応

| コンポーネント | ダッシュボード時の変更 |
|---|---|
| **経済指標カレンダー** | ヘッダーバーに統合。アイコン（赤/黄/グレー）+ クリックで展開 |
| **ニュース** | ヘッダーバーに統合。アイコン + クリックで展開 |
| **結論** | 変更不要（既にコンパクト） |
| **PR比較** | Long/Shortを**縦並び**に変更（横幅が狭い左列に合わせる） |
| **売買シミュレーター** | 高さをviewportに合わせるflex調整。内部レイアウトは維持 |
| **ポジション管理** | max-height固定 + overflow-y-auto（内部スクロール） |
| **分析履歴** | 折畳→常時表示に変更。max-height固定 + overflow-y-auto |

---

## 実装方針

1. `page.tsx` の簡易版ブロックに **CSS Grid wrapper** を追加
2. 各コンポーネントは grid area に配置（コンポーネント内部の変更は最小限）
3. Tailwindのレスポンシブプレフィックスで切替: `xl:grid-cols-...`, `2xl:...`
4. PR比較の縦並びモードは props or className で制御
5. 下段コンポーネントに `max-h-[250px] overflow-y-auto` を外部から付与

**変更ファイル（想定）:**
- `src/app/page.tsx` — Grid wrapper追加、レスポンシブ切替
- `src/components/PRComparison.tsx` — 縦並びモード対応（minor）
- 各コンポーネントへのclassName透過（必要に応じて）

---

## 考慮事項

- **分析未実行時**: ダッシュボードのグリッド構造は維持し、各エリアにプレースホルダーを表示
- **ポジション0件時**: ポジション管理エリアは「ポジションなし」の表示でスペースを維持
- **ウィンドウリサイズ**: Tailwindのレスポンシブが自動対応。JS不要
- **印刷**: 考慮外（現状も未対応）
