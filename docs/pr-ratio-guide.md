# PR比較（リスクリワード比）の計算ロジック解説

## PR比ってなに？

PR比とは「**1回のトレードで、リスク（損する金額）に対してリワード（得する金額）がどれくらいあるか**」を表す数字です。

```
PR比 = 利益 ÷ リスク
```

例えば PR比 = 3 なら、「損する金額の3倍の利益が見込める」という意味です。

---

## 登場する4つの数字

| 項目 | 意味 | ひとことで言うと |
|------|------|------------------|
| **エントリー** | 取引を始める価格 | 「ここで買う（or 売る）」 |
| **損切り** | 「予想が外れた」と判断してやめる価格 | 「ここまで来たら諦める」 |
| **利確** | 「予想通りになった」と判断して利益を確定する価格 | 「ここまで来たら勝ち」 |
| **PR比** | 利確までの距離 ÷ 損切りまでの距離 | 「勝ち幅は負け幅の何倍？」 |

---

## ロング（値上がりを予想する取引）の場合

ロングは「安く買って、高く売る」取引です。

```
                利確  ← ここまで上がったら勝ち（利益を確定）
                 ↑
                 ↑  ← この距離が「利益」
                 ↑
        エントリー  ← ここで買う
                 ↓
                 ↓  ← この距離が「リスク」
                 ↓
               損切り  ← ここまで下がったら負け（損失を確定）
```

**計算例（画像のロングの場合）:**

```
エントリー:  $69,296.39（ここで買う）
損切り:      $68,480.01（ここまで下がったらやめる）
利確:        $71,748.51（ここまで上がったら利益確定）

リスク = エントリー − 損切り = $69,296.39 − $68,480.01 = $816.38
利益   = 利確 − エントリー = $71,748.51 − $69,296.39 = $2,452.12

PR比 = $2,452.12 ÷ $816.38 = 3.0
```

→ 勝った場合、負けた場合の**3倍**の利益が得られる。

---

## ショート（値下がりを予想する取引）の場合

ショートは「高く売って、安く買い戻す」取引です。ロングとは上下が逆になります。

```
               損切り  ← ここまで上がったら負け（損失を確定）
                 ↑
                 ↑  ← この距離が「リスク」
                 ↑
        エントリー  ← ここで売る
                 ↓
                 ↓  ← この距離が「利益」
                 ↓
                利確  ← ここまで下がったら勝ち（利益を確定）
```

**計算例（画像のショートの場合）:**

```
エントリー:  $70,119.65（ここで売る）
損切り:      $70,422.14（ここまで上がったらやめる）
利確:        $69,296.39（ここまで下がったら利益確定）

リスク = 損切り − エントリー = $70,422.14 − $70,119.65 = $302.49
利益   = エントリー − 利確 = $70,119.65 − $69,296.39 = $823.26

PR比 = $823.26 ÷ $302.49 = 2.72
```

→ 勝った場合、負けた場合の**2.72倍**の利益が得られる。

## 各価格はどうやって決めているの？

### エントリー（いくらで入るか）

**「現在価格の近くにあるサポート・レジスタンスを使う」**

- **ロング** → 現在価格のすぐ下にある**サポートライン**（過去に何度も跳ね返された価格帯）
- **ショート** → 現在価格のすぐ上にある**レジスタンスライン**（過去に何度も上値を抑えられた価格帯）

```
サポート・レジスタンスとは？

「壁」のようなものです。
過去に何度も同じ価格で跳ね返されていると、そこに見えない壁があるように振る舞います。

  レジスタンス（上の壁）：この価格を超えにくい
  ─────────── $71,000 ───────────
       ↕ この間で価格が動く
  ─────────── $69,000 ───────────
  サポート（下の壁）：この価格を下回りにくい
```

これらのサポート・レジスタンスは、複数の時間足（5分・15分・1時間・4時間・日足）のチャートデータから自動検出しています。長い時間足で確認されたラインほど「強い壁」として重視されます。

さらに、出来高プロファイル（VRVP）からも壁を検出します。たくさん取引された価格帯は強い壁になりやすいためです。

---

### 損切り（いくらで諦めるか）

**「エントリーの反対側にあるサポート・レジスタンスの少し外側」**

具体的な手順:

1. ロングの場合 → エントリーより下のサポートラインを探す
2. ショートの場合 → エントリーより上のレジスタンスラインを探す
3. その壁の**少し外側**（0.1%分のバッファ）に損切りを置く

```
ロングの例:
  エントリー $69,296
        ↓
  サポート   $68,550（ここが壁）
  損切り     $68,480（壁の少し下 ← ここを突き抜けたら壁が壊れた証拠）
```

**安全装置（ATRガードレール）:**

ATR（一定期間の平均的な値動き幅）を使って、損切りが近すぎたり遠すぎたりしないようにチェックします。

```
ATRとは？ → 「最近、価格が1本のローソク足で平均どれくらい動くか」を表す数字

例: BTC の ATR が $900 の場合
  損切りの最小距離 = $900 × 0.3 = $270（これより近いと、すぐ狩られる）
  損切りの最大距離 = $900 × 1.5 = $1,350（これより遠いと、リスクが大きすぎる）
```

もし壁が見つからない場合は、ATR × 0.7 の距離をデフォルトとして使います。

---

### 利確（いくらで勝ちにするか）

**「エントリーの先にあるサポート・レジスタンス」**

具体的な手順:

1. ロングの場合 → エントリーより上のレジスタンスラインを探す
2. ショートの場合 → エントリーより下のサポートラインを探す
3. 十分な距離（ATR × 0.5 以上）離れたラインを選ぶ

```
ロングの例:
  利確       $71,748（ここが次の壁 ← ここで上昇が止まりやすい）
        ↑
  エントリー $69,296
```

**PR比の最低ライン:**

- もしPR比が1.5未満になる場合 → もっと遠い壁を探す
- それでもPR比が1.0未満の場合 → リスクの1.5倍の距離に利確を自動設定

```
なぜ最低ラインがあるの？

PR比が1.0未満 = 「負ける額のほうが勝つ額より大きい」
これではたとえ勝率50%でもトータルで損します。
最低でもPR比1.5（勝ちが負けの1.5倍）は確保するようにしています。
```

---

## まとめ: 計算の全体の流れ

```
① 複数の時間足のチャートデータからサポートとレジスタンスを検出
     ↓
② サポレジを統合して「強い壁」のリストを作る
     ↓
③ 現在価格に最も近い壁をエントリーに使う
   ・ロング → 下の壁（サポート）
   ・ショート → 上の壁（レジスタンス）
     ↓
④ エントリーの反対側の壁を損切りに使う
   ・ATRで近すぎ/遠すぎをチェック
     ↓
⑤ エントリーの先の壁を利確に使う
   ・PR比 1.5以上になる壁を選ぶ
     ↓
⑥ PR比を計算して、ロングとショートを比較表示
```

---

## 「PR比が高い方」の判定

ロングとショート両方のPR比を比較して、**数字が大きい方**を「期待値が高い方」として表示しています。

ただし、PR比が高い＝必ず勝てる、ではありません。あくまで「**勝った時のリターンが負けた時のリスクに対して大きい**」ということです。実際に勝てるかどうかは、トレンドやその他の分析指標と合わせて判断する必要があります。
