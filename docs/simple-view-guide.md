# Cryptocurrency Outlook 簡易版 — 各項目の見方

## 画面構成（上から順）

---

### 1. 経済指標カレンダー

米国の重要経済イベント（FOMC、CPI、雇用統計等）の今後48時間の予定を表示。
分析前（ページ読み込み時）から表示されます。

| 色 | 状態 | 意味 |
|----|------|------|
| 赤 | 発表間近（6時間以内） | 高インパクトイベントが迫っている。**エントリー非推奨**。結論が強制的に「様子見」になる |
| 黄 | 注意（24時間以内） | 高インパクトイベントが控えている。結論の理由に注意喚起が追記される |
| グレー | なし | 48時間以内に重要イベントなし |

**見方**: 赤表示の時はどんなに良いシグナルが出ていてもエントリーを控える。発表直後は急変動するため、結果を確認してから判断する。

### 2. 結論

テクニカル指標・デリバティブデータ・階層分析・センチメント・経済カレンダーを**総合的に判断**した最終結論。

| ラベル | 色 | 意味 |
|--------|-----|------|
| ロングエントリー推奨 | 緑 | 買い（価格上昇を見込む）のシグナルが優勢 |
| ショートエントリー推奨 | 赤 | 売り（価格下落を見込む）のシグナルが優勢 |
| 引きつけて待機 | 黄 | シグナルはあるが、より良い価格まで待つべき |
| 見送り推奨 | グレー | 明確なシグナルなし。トレードしない方が良い |

**理由テキストの読み方**:
- `強気シグナル優勢 (4.5 vs 2.5)` → ロング根拠4.5点、ショート根拠2.5点
- `[15m↓ / 1h↑ / 4h↑ / 1d↑]` → 各時間足のトレンド方向
- `ロングのPR比1.53` → リスク1に対してリワード1.53
- `[階層分析: ...]` → 長い足から短い足への方向性の整合性
- `→ 1h戦略: ...` → 推奨する具体的な戦略

**注意**: 結論はあくまで現時点のデータに基づく分析であり、将来の値動きを保証するものではない。

### 3. PR比較 (Long vs Short)

ロングとショート両方のトレードプランを**リスクリワード比（PR比）で純粋に比較**する。

| 項目 | 説明 |
|------|------|
| エントリー | 指値注文を入れる価格（ロング＝サポート付近、ショート＝レジスタンス付近） |
| 損切り | 損失を限定するための決済価格。()内は現在価格からの距離(%) |
| 利確 | 利益を確定する目標価格。()内は現在価格からの距離(%) |
| PR比 | リスク（損切りまでの幅）に対するリワード（利確までの幅）の比率 |

**PR比の目安**:
- 2.0以上（緑）: 優秀。リスク1に対してリワード2以上
- 1.5〜2.0（黄）: 許容範囲
- 1.5未満（赤）: 効率が悪い

**「PR比が高い方」の表示**: 単純にPR比が高い方を示すが、**結論と一致しないことがある**。これは正常。結論はトレンド・モメンタム・出来高等を含めた総合判断だが、PR比は損益比率のみの評価。トレンドに逆らう方がPR比は良くなりやすいが、成功確率が低い。

### 4. 売買シミュレーター

結論で推奨された方向のトレードを、具体的な金額でシミュレーションする。

#### 入力項目（左右並び）
- **投資金額 (USDT)**: 取引に使う元手
- **レバレッジ**: 元手を何倍にして取引するか（1x〜40x）
  - 10x未満: 白表示（低リスク）
  - 10x〜19x: 黄表示（中リスク）
  - 20x以上: 赤表示（高リスク）

#### 方向タブ
- **ロング（買い）/ ショート（売り）**: 分析結果に基づいて自動選択されるが手動で切替可能

#### 価格入力（3列）
- **エントリー**: 分析結果から自動設定。手動変更時は青枠で表示
- **損切り**: 同上
- **利確**: 同上

#### 計算結果
- **ポジションサイズ**: 投資金額 × レバレッジ = 実際に動かす金額
- **リスクリワード比**: 1 : X（損切り幅に対する利確幅の比率）

#### 損益表示（左右並び）
- **利確時（左・緑）**: 利確価格に達した場合の利益額と投資金額に対するROI(%)
- **損切り時（右・赤）**: 損切り価格に達した場合の損失額と投資金額に対するROI(%)

#### 推定清算価格（黄色）
レバレッジ取引で証拠金が0になる価格。この価格に達すると**全額を失う**。レバレッジが高いほどエントリー価格に近づく。

#### ポジション保存
「ポジション保存」ボタンで仮想ポジションとして保存可能（最大50件、アクティブポジションのみカウント）。

**注意**: 画面右上に記載の通り、手数料・Funding Rateは計算に含まれていない。実際の損益はこれより若干少なくなる。

### 5. 保存済みポジション

保存したポジションの管理画面。ポジションは3つの状態を持つ。

| 状態 | 意味 | 操作 |
|------|------|------|
| 待機中 | 指値注文を出した状態（まだ約定していない） | 「約定」で建玉に変更、「削除」で取消 |
| 建玉中 | ポジションを保有中。リアルタイムで損益が更新される | 「決済」で手動決済 |
| 決済済み | 決済が完了したポジション。最終損益が確定 | 記録として残る |

### 6. 分析履歴

過去の分析結果を自動保存し、的中/外れを判定する。

#### 表示内容（各エントリ）
- **日時**: 分析実行時刻（JST）
- **銘柄**: 分析した通貨ペア
- **結論**: ロング/ショート/様子見/スキップ
- **信頼度**: 分析の確信度（0〜100%）
- **残り時間 / 期限切れ**: 判定期間の残り
- **価格比較**: `分析時 $XX,XXX → 現在 $XX,XXX +X.XX%`
- **判定バッジ**: 的中/外れ/判定中/正解/機会損失

#### 判定ロジック

| 結論 | 条件 | 判定 |
|------|------|------|
| ロング推奨 | +1%以上上昇 | 的中（緑） |
| ロング推奨 | -1%以上下落 | 外れ（赤） |
| ロング推奨 | ±1%未満 | 判定中（グレー） |
| ショート推奨 | -1%以上下落 | 的中（緑） |
| ショート推奨 | +1%以上上昇 | 外れ（赤） |
| ショート推奨 | ±1%未満 | 判定中（グレー） |
| 様子見/スキップ | ±2%未満 | 正解（緑） |
| 様子見/スキップ | ±2%超 | 機会損失（黄） |

#### 判定期間（分析時の最長時間足に連動）

| 最長時間足 | 判定期間 |
|-----------|---------|
| 5分足 | 4時間 |
| 15分足 | 8時間 |
| 1時間足 | 12時間 |
| 4時間足 | 24時間 |
| 日足 | 72時間 |

期限を過ぎた履歴は半透明で「期限切れ」と表示され、判定は行われない。

#### エクスポート / インポート
- **エクスポート**: 履歴をJSONファイルとしてダウンロード（バックアップ用）
- **インポート**: JSONファイルから履歴を復元（重複は自動スキップ）

## 簡易版 vs 詳細版の違い

簡易版は**判断に必要な最小限の情報**に絞って表示。詳細版では以下が追加される:

- マーケットサマリー（24h変動、出来高、OI、ファンディングレート）
- トレンド分析（各時間足のトレンド方向・強度）
- サポート/レジスタンスレベル一覧
- ブレイクアウトレベル
- 詳細結論（パターン、デリバティブ分析、出来高プロファイル、清算ゾーン等）
- AI分析用プロンプトコピー
